# 🐾 Animal con Node.js

Este proyecto es una aplicación web simple desarrollada con **Node.js y Express**, que permite ingresar el nombre de un animal en un formulario y mostrarlo en una segunda vista.

---

##🚀 Funcionamiento del proyecto

1. El usuario ingresa el nombre de un animal en un formulario.
2. El servidor Node.js recibe la información mediante una petición POST.
3. Se redirige a una segunda página donde se muestra el animal ingresado.
4. El resultado se muestra dinámicamente en pantalla.

---

## 🧠 Tecnologías utilizadas

- Node.js
- Express
- Body-Parser
- HTML5
- CSS3
- JavaScript
